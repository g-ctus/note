## 問：驚くべきリンクを"偶然"に頼らず作るには？

> Now, for us, I’ve juxtaposed this so that the connection is obvious. In the example of years later and forgetting about the categorical imperative card, I see two options.
>
> 1. My brain still makes the connection, and so I didn’t need Obsidian or Zettelkasten.
> 2. I don’t see the connection, and I can’t fathom any sorts of tags/links that would get this very clear connection to naturally emerge from the system.

1. ノートAに対してノートBがリンクできることを"偶然"見つけられるなら,ObsidianやZettelkastenを使う意味はなに？
2. 驚くべきリンクを得られるようなタグやリンクの整理方法が見つけられていない

## 回答：

> Don’t rely on single-degree connections - they are close to useless. ...... from experience it builds cobwebs of underutilised information that never see the light of day.

1次元的なリンクは無用であり,経験上そのようなリンクは二度と見返すことがない.

> 1. Go at least 2 degrees deep, and make this quickly accessible so that it doesn’t become troublesome.
> 2. Make note titles like APIs
> 3. Whenever you create a note, always create \[\[access points\]\] like these.
> 4. A quick way to create new notes, or “thought sequences”. I call this Threading, which I use the Breadcrumbs plugin for.
> 5. Another way to pull up “distant links” is to use the [Obsidian Sidekick plugin](https://github.com/hadynz/obsidian-sidekick/) which you can install through the Obsidian42 BRAT plugin.

1. 二次以上のリンクを作成し，かつそれに容易にアクセスできるようにする
2. ノートタイトルをAPIのようにする（タイトルでアトミックノートの内容を理解できるようにする）
3. ノートを作るときは必ず\[\[アクセスポイント\]\]リンクを作成する．
4. 新しいノートや思考の連鎖を素早く記録する方法を準備しておく．私は`Breadcrumbs`プラグインを使っている．
5. Obsidian Sidekick pluginなら，"distant links"を素早く見つけられるかもしれない
